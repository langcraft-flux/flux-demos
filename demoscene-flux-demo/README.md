# Flux Demo

A tiny demoscene-style browser trackmo: starfield, tunnel, plasma, chrome title card, scrolling greets, and procedural WebAudio.

## Run

Simplest option:

```bash
cd /Users/openclaw/.openclaw/workspace/demoscene-demo
python3 -m http.server 8000
```

Then open:

- <http://localhost:8000>

Click **Start Demo** (or press space) to begin audio + visuals.
